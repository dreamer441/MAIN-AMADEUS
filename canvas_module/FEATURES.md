# Canvas Module Features

## Implemented Now

- First-class `CanvasModule` facade registered through AMADEUS Core.
- Stable `CanvasWorkspaceDescriptor` for GUI mounting and future schema evolution.
- Persistent Canvas page in the main GUI navigation.
- Large infinite-style `QGraphicsScene` workspace.
- Mouse-drag panning.
- Cursor-centred wheel zoom with bounded scale.
- Adaptive visual grid and honest foundation-status guidance.
- Lazy GUI imports so non-GUI Canvas models and services remain independently importable.

## Current Boundary

The current phase creates the Canvas module space only. It does not yet implement text blocks, selection, connectors, storage, context injection, AMADEUS responses, handwriting, or image support.
